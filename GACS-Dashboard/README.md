# GACS Dashboard v1.1.0-beta

Dashboard monitoring jaringan GenieACS (PHP 8.3 + MySQL/MariaDB) dengan peta topologi Leaflet, grafik Chart.js, dan notifikasi Telegram.

## Panduan instalasi
- [Instalasi di Ubuntu / Proxmox (Nginx)](INSTALL-UBUNTU.md)
- [Instalasi di hosting (cPanel, CloudPanel, aaPanel)](INSTALL.md)

## Keamanan singkat
Login awal `user1234` / `mostech` wajib diganti pada login pertama. Hapus `init.php` setelah instalasi selesai. Jangan commit file `.env`.
